# Proyectos_Internos

## Reparto

App de gastos compartidos (hogar / paseos) con reparto proporcional por ingresos.
Instalable en teléfono y PC (PWA), con vista por mes, búsqueda y plantillas repetibles.

```bash
cd reparto
npm install
npm run dev
```

Ver detalles en [`reparto/README.md`](reparto/README.md).
